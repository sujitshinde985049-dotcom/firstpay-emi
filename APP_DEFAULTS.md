# Approved Phase 1 Defaults

- Android application ID: `com.firstpay.app`
- iOS bundle ID: `com.firstpay.app`
- Minimum Android: Android 8.0 / API 26
- Custom auth link: `firstpay://auth/reset-password`
- Production auth link: `https://app.firstpay.in/auth/reset-password`
- Offline: read-only previously synchronized data; no offline mutations
- Timestamps: store UTC, display `Asia/Kolkata`
- Case-insensitive unique: registration number, short code, employee code, branch code
- Company: FirstPay Technologies
- App: FirstPay
- Android first; keep iOS-compatible; no release APK in Step 2
